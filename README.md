# Vice Bloxy

A neon-coast open-world crime game for Roblox, inspired by Vice City-style settings. Original name and assets only.

## Setup
1. `rojo serve` in this folder.
2. In Roblox Studio, install the Rojo plugin and click Connect.
3. Press Play.

## Layout
- `src/server`: server scripts (cash, jobs)
- `src/client`: client scripts (HUD)
- `src/shared`: shared config
